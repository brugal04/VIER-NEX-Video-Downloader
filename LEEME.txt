VIER-NEX Video Downloader v0.1.0
=================================

Creado por Bryant Brugal
Proyecto: VIER-NEX

SPRINT COMPLETO
---------------
Esta versión integra en un solo sprint:

INTERFAZ / WINDOWS
- Nueva interfaz dark cyan / blue / purple.
- Icono de ventana y barra de tareas.
- Bandeja del sistema.
- Doble clic en bandeja abre VIER-NEX.
- Cerrar con X minimiza a bandeja.
- Menú rápido de bandeja.
- Notificaciones de Windows con fallback a bandeja.
- Progreso en barra de tareas cuando Windows/comtypes lo permite.
- Launcher normal sin consola.
- Modo Debug separado.

DESCARGAS
- Twitter/X, TikTok, Instagram, Facebook, Reddit, YouTube, Vimeo, Twitch
  y otros sitios compatibles con yt-dlp.
- WhatsApp ~170 MB.
- Tamaño personalizado.
- Máxima calidad.
- Auto / calidad inteligente.
- 1080p.
- 720p.
- MP3.
- Uso opcional de sesión de Chrome.

ANÁLISIS
- Análisis del enlace antes de descargar.
- Título.
- Plataforma.
- Resolución.
- Duración.
- Tamaño estimado cuando la plataforma lo informa.
- Salida objetivo estimada.

COLA / LOTE
- Múltiples enlaces.
- Cola persistente.
- Pausar / continuar descarga actual.
- Cancelar.
- Reintentar fallidas.
- Quitar elementos.
- Limpiar terminadas.

DRAG & DROP
- Arrastra URLs a la aplicación para añadirlas.
- Arrastra videos locales para comprimirlos.

PORTAPAPELES
- Detección automática.
- Descargar.
- Descargar en modo WhatsApp.
- Ignorar.
- Notificación opcional.

HISTORIAL
- Archivo.
- Plataforma.
- Tamaño.
- Fecha.
- Abrir archivo.
- Abrir carpeta.
- Copiar URL original.
- Repetir descarga.
- Eliminar del historial.

ACERCA DE
- Nombre.
- Versión.
- Creado por Bryant Brugal.
- Descripción.
- Tecnologías.
- Privacidad.
- Información de versión.

ACTUALIZACIONES
- Muestra versión instalada de yt-dlp.
- Consulta versión actual disponible.
- Actualización automática de yt-dlp cuando se ejecuta desde Python.
- En el EXE, el motor está integrado y se actualiza al generar una nueva versión.

PRIVACIDAD
- Procesamiento local.
- Sin telemetría.
- El historial no se envía fuera de la PC.

PRIMERA VEZ
-----------
1. Descomprime el ZIP.
2. Ejecuta:
   INSTALAR_PRIMERA_VEZ.bat

Después de la instalación, usa:
   ABRIR_VIER_NEX.vbs

Ese launcher abre la interfaz SIN consola.

MODO DEBUG
----------
Si algo falla:
   ABRIR_MODO_DEBUG.bat

También revisa:
C:\Users\TU_USUARIO\AppData\Local\VIER-NEX Video Downloader\startup_error.txt

CREAR EXE
---------
Ejecuta:
   CREAR_EXE_WINDOWS.bat

Resultado:
dist\VIER-NEX Video Downloader.exe

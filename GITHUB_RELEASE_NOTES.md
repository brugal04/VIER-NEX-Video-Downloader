# VIER-NEX Video Downloader v0.1.0

Primera versión pública de VIER-NEX Video Downloader para Windows.

## Highlights

- Descarga videos desde YouTube, Facebook, Instagram y TikTok.
- Analiza enlaces antes de descargar.
- Modos Auto, 1080p, 720p, MP3, WhatsApp y tamaño personalizado.
- Cola de descargas e historial.
- Soporte para Facebook Reel, Watch, Share y fb.watch.
- Normalización y resolución de enlaces compartidos de Facebook.
- Soporte de sesión del navegador para contenido de Facebook que requiere autenticación.
- Corregida la descarga de videos verticales 1080x1920.
- Corregido el falso error de "video privado/eliminado" causado por formatos no disponibles.
- Soporte de browser impersonation con curl_cffi para TikTok.
- YouTube, Facebook, Instagram y TikTok validados en la versión actual.
- Manual de usuario PDF integrado.
- Instalador nativo para Windows mediante Inno Setup.
- SHA-256 incluido para verificar la integridad del instalador.

## Requisitos

- Windows 10/11 x64.
- Conexión a Internet.

## Release assets

- `VIER-NEX-Video-Downloader-Setup-v0.1.0.exe`
- `SHA256SUMS.txt`

## Nota

La compatibilidad con plataformas puede cambiar cuando YouTube, Facebook, Instagram o TikTok modifican sus sistemas. VIER-NEX Video Downloader utiliza yt-dlp como motor de descarga.

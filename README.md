# VIER-NEX Video Downloader



Aplicación para Windows que permite descargar videos desde YouTube, Facebook, Instagram y TikTok.



**Versión actual: v0.1.0**



## Características



- YouTube, Facebook, Instagram y TikTok

- Modos Auto, 1080p, 720p y MP3

- Modo WhatsApp y tamaño personalizado

- Análisis previo del enlace

- Cola e historial de descargas

- Soporte para Facebook Reels y enlaces compartidos

- Videos verticales 1080x1920

- Soporte de sesión del navegador

- Soporte TikTok mediante curl\_cffi

- Manual PDF integrado



## Descargar



Última versión:



https://github.com/brugal04/VIER-NEX-Video-Downloader/releases/latest



Instalador:



`VIER-NEX-Video-Downloader-Setup-v0.1.0.exe`



## Requisitos



- Windows 10/11 de 64 bits

- Conexión a Internet
